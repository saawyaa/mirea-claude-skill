# Диагностика

## Вход

**Форма входа вместо страницы.** Навигация на `https://online-edu.mirea.ru/auth/oidc/?source=loginpage`,
дальше пользователь вводит данные сам. Никогда не заполнять поля за него.

**Сессия жива?** На странице СДО: `!!(window.M && M.cfg && M.cfg.sesskey)`.

**Пульс просит войти, хотя СДО открыт.** Перейти на
`/api/auth/login?redirectUri=https%3A%2F%2Fpulse.mirea.ru%2Fservices&rememberMe=True` — сессия втянется молча.

## Ошибки скриптов

| Симптом | Причина | Что делать |
|---|---|---|
| `servicerequireslogin` | сессия истекла | переоткрыть СДО, попросить войти заново |
| `invalidtoken` | зашли не тем путём | токены не используются, брать `sesskey` со страницы |
| `servicenotavailable` | метод не ajax-совместим | фолбэк на страницу, см. `api.md` |
| `НЕ ТА СТРАНИЦА` от коллектора Пульса | не на `/lessons/visiting-logs` | перейти и подождать ~4 с |
| статус сдачи «?» | взят `action.url` вместо `url` | см. грабли в `api.md` |
| месяц определился неверно | regex поймал слово из карточки | искать связку «месяц ГОД» |
| `localStorage.getItem(...)` вернул `null` | панель перезапускали, кэш пуст | вставить файл коллектора заново |

## Пустая сводка

Пустые блоки коллектор выкидывает сам. Если пусто всё — сначала проверить сессию, потом горизонт:
`window.__MH = 30` перед вставкой.

## Что осознанно не сделано

**Фоновый автозапуск по расписанию невозможен.** Нет токена — нужна живая сессия браузера. Сводка только
по запросу. Не обещать пользователю ежедневный автодайджест: не поедет.
