# mirea-claude-skill

Скилл для [Claude Code](https://claude.com/claude-code): сводки по учёбе в РТУ МИРЭА — дедлайны, статусы сдачи, расписание, посещаемость и баллы БРС из **СДО** и **Пульса** одной командой.

```
🔥 СРОЧНО (< 48 ч)
  27.09 23:58 · Рабочая тетрадь 3 · Информатика · НЕ СДАНО
📍 СЕГОДНЯ пн 21.09
  14:20 ПР Физика · А-107-1
  16:20 ЛК Математический анализ · А-10 · Муханов С. А.
📊 Посещаемость (2 нед.): отмечено 13, без отметки 2
БРС · Информатика  ЭКЗ  2.5/120  до «3»: ещё 37.5 · посещение +2.5
```

## Что умеет

| Спросить | Получить |
|---|---|
| «сводка» | всё сразу: дедлайны, пары, посещаемость |
| «дедлайны», «что задали» | сроки с реальным статусом сдачи, а не догадками |
| «расписание», «что сегодня» | пары с аудиториями и преподавателями |
| «посещаемость» | отметки за выбранное число недель |
| «баллы», «БРС» | баллы по всем предметам и сколько до порога |
| «сколько баллов по физике» | разбивка: текущий контроль, посещаемость, достижения |

Второй запуск показывает **только изменения**: `✓ сдано`, `★ оценили`, `+ новый срок`, `↑ баллы выросли`.

## Установка

```bash
git clone https://github.com/saawyaa/mirea-claude-skill ~/.claude/skills/mirea
```

Настраивать нечего: ни токенов, ни ключей, ни конфигов.

## Первый запуск

Сказать Claude Code «сводка по МИРЭА». Откроется панель браузера с формой входа МИРЭА — **логин и пароль вводишь сам**, Claude их не касается. Пульс после этого подхватится без повторного входа: SSO общий.

## Как это устроено

СДО — это Moodle с Keycloak-авторизацией. Токены веб-сервисов студентам не выдают, а `login/token.php` не работает с SSO-аккаунтами. Поэтому скилл ходит в тот же внутренний API через `sesskey` живой сессии браузера — ровно так, как это делает сама страница СДО.

Пульс работает на gRPC-web, поэтому читается через DOM.

**Вся агрегация выполняется внутри страницы**, наружу возвращается готовый короткий текст. Это сделано ради расхода токенов подписки: одна сводка вместо десятка сырых JSON-ответов. Скрипт кэширует сам себя в `localStorage`, поэтому повторный вызов в той же сессии стоит одну строку.

## Чего скилл не делает

- **Не вводит пароли.** Никогда, ни в какой форме.
- **Не сдаёт и не отправляет работы** без явного подтверждения в чате.
- **Не работает в фоне по расписанию.** Без токена нужна живая сессия браузера, поэтому автодайджеста по крону не будет — только по запросу.
- **Не утверждает, что у тебя прогул.** «Н» в журнале означает отсутствие отметки; она могла просто не сработать.

## Источники расходятся — и это нормально

По БРС источник истины — Пульс. Ведомость курса в Moodle преподаватель может не вести: проверено на живом курсе, где Пульс показывал начисленные баллы, а таблица в СДО была пустой целиком. При расхождении скилл верит Пульсу и говорит об этом.

## Статус

Всё перечисленное проверено на живом аккаунте студента 1 курса. Не обкатана только диф-логика на реальном изменении: за время разработки баллы и статусы не успели поменяться, так что сравнение «с прошлого раза» пока срабатывало лишь на искусственных данных.

Структура БРС (0–40 / 0–20 / 0–10 / 0–40, сумма 0–120) взята с курсов первого курса. У других институтов и старших курсов шкалы могут отличаться — физкультура, например, уже идёт из 15.
